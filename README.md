# SkyCast---Weather-Dashboard

SkyCast is a modern and responsive weather dashboard built using HTML, CSS, and JavaScript. The application allows users to search for weather information in cities worldwide and view real-time weather data through a clean, intuitive, and user-friendly interface.

## Features

* Real-time weather search by city name
* Current temperature and weather conditions
* Current local time for the selected location
* Feels-like temperature information
* Humidity and wind speed details
* Dynamic weather-based themes
* Current location weather support
* Search history using Local Storage
* Loading states and error handling
* Fully responsive design for desktop, tablet, and mobile devices

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Open-Meteo Weather API
* Open-Meteo Geocoding API
* Font Awesome

## How It Works

Users can search for any city to retrieve current weather information. The application fetches real-time weather data from the Open-Meteo API and presents it in a visually appealing dashboard. Users can also use their current location to access local weather conditions. The interface automatically adapts based on weather conditions and time of day to enhance the overall user experience.
